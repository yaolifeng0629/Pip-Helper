## 功能特点

-   **可靠的原生画中画**：可通过弹窗、右键菜单或快捷键进入、退出浏览器原生画中画
-   **可见视频优先**：优先选择当前可见且正在播放的视频；存在多个同等候选时交由你选择
-   **当前网站快捷开关**：可直接在弹窗中允许或限制当前网站
-   **明确的网站规则**：支持“默认允许，仅限制指定网站”与“默认限制，仅允许指定网站”两种模式
-   **实时状态**：弹窗会反映动态视频发现、画中画会话、不可用页面和浏览器不支持等状态

## 快捷键

-   `Alt+P`：激活画中画模式
-   `Alt+B`：返回当前浏览器标签页

## 浏览器兼容性

-   Chrome / Edge / Opera / Brave 等基于 Chromium 的浏览器
-   Firefox (使用 `pnpm dev:firefox` 和 `pnpm build:firefox` 命令)

## 开发

Pip-Helper 使用 Plasmo 构建。Chrome MV3 开发使用 `pnpm dev`，生产构建使用 `pnpm build`；Firefox MV3 使用对应的 `:firefox` 命令。
